# Analysis

Artefak analisis per kebutuhan, satu folder per kebutuhan:
`analysis/<NNN>-<slug>/` atau `analysis/<ISSUE-ID>-<slug>/` bila ada issue tracker.

Tiap folder berisi: `analysis.md`, `flow.mmd`, `sequence.mmd`, dan opsional `erd.mmd`.

Folder ini di-commit dengan sengaja — ini catatan kenapa sesuatu dibangun dengan cara
tertentu, untuk Anda di masa depan dan untuk sesi Claude berikutnya. Jangan gitignore.

Artefak di sini tidak pernah disunting setelah ditulis. Bila pemahaman berubah, tulis
analisis baru — jangan menulis ulang yang lama.
